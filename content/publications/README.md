# Публикации

Оригинал и переводы одной публикации хранятся в одной записи в `data.json`. Поле `slug` задаёт общий адрес, а `sourceLocale` принимает `ru` или `en`.

```json
{
  "slug": "my-article",
  "sourceLocale": "ru",
  "versions": {
    "ru": {
      "status": "draft",
      "title": "Заголовок",
      "summary": "Краткое описание",
      "paragraphs": ["Первый абзац.", "Второй абзац."]
    }
  }
}
```

1. Добавь запись в массив `data.json` или передай Codex текст и язык оригинала.
2. Попроси Codex заполнить девять остальных версий со статусом `draft`. При переводе нужно сохранить факты и структуру оригинала и свериться с `glossary.json`. В глоссарий добавляй точные фразы, которые должны сохраняться в каждой версии.
3. Запусти `npm run check:content`. Команда перечислит отсутствующие языки и черновики, проверит поля и найдёт пропущенные термины. При изменении оригинала верни затронутые переводы в `draft` и обнови их перед повторным одобрением.
4. Прочитай тексты и выставь `approved` оригиналу и каждой готовой версии. После сборки сайт автоматически добавит их в раздел публикаций и свяжет одобренные версии через hreflang.

Черновики и отсутствующие версии не получают публичных страниц. Проверка терминов ищет точные строки. Смысл, грамматику и термины в контексте проверяет редактор.
