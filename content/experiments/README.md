# Эксперименты LAB

## Подключение Marine Ecosystem

Задайте `MARINE_ECOSYSTEM_WEBGL_URL` в локальном `.env.local` или в настройках нужного окружения Vercel. Значение должно указывать на HTTPS-адрес страницы запуска Unity WebGL. Добавьте точный origin хостинга в `approvedFrameOrigins` в `approved-origins.mjs` и пересоберите приложение. Значение URL без разрешённого origin не запускается.

Хостинг должен разрешать встраивание с доменов NextAIism и отдавать файлы Unity с правильными заголовками MIME и сжатия. iframe запускает скрипты в sandbox с непрозрачным origin. Проверьте CORS загрузчика и файлов Unity в Preview, особенно если сборка использует потоки, хранилище или специальные заголовки изоляции. Для несовместимой сборки используйте режим `external` с отдельно одобренным HTTPS-origin. Загрузка iframe начинается только после нажатия кнопки запуска. Браузер может вызвать событие load даже при блокировке iframe, поэтому ссылка на отдельную вкладку остаётся доступна и после загрузки.

## Новый эксперимент

1. Добавьте запись в `catalog.ts` с уникальными id и slug, обложкой из `public/experiments`, категорией, статусом и режимом запуска. Для независимого автора используйте `author.type: "guest"` и его имя.
2. Добавьте английскую версию в `materials.ts`, затем готовые локализации. При отсутствии перевода сайт явно помечает показ английского материала. Наблюдения принимают ISO-даты формата YYYY-MM-DD, ссылки на публикации используют slug одобренной статьи.
3. Проверьте автора, домен, перенаправления и содержимое. Для `iframe` внесите точный origin в `approvedFrameOrigins`, для `external` — в `approvedExternalLaunchOrigins`. Используйте выделенный хост приложения. Для `internal` зарегистрируйте компонент из этого репозитория в `app/[locale]/lab/internal-experiments.ts`.
4. После проверки выставьте `approved: true`. Сайт сам сформирует карточку и страницу по адресу `/<locale>/lab/<slug>`. Для запуска используйте статус `development` или `live`.
